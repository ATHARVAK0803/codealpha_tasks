# CodeAlpha Power BI Internship Tasks

This repository contains the Power BI projects completed as part of my **CodeAlpha Power BI Internship**.

The projects demonstrate practical skills in data analysis, data transformation, data modeling, DAX, KPI development, and interactive dashboard design using Microsoft Power BI.

---

## 📂 Completed Tasks

### Task 1 – Financial Performance Dashboard

An interactive financial dashboard developed to analyze overall financial performance through key financial metrics and visualizations.

**Key areas covered:**
- Financial performance analysis
- Profitability analysis
- Budget vs Actual analysis
- Balance Sheet analysis
- Cash Flow analysis
- Financial ratio analysis
- Interactive KPI visualization

**Tools & Technologies:**
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

📁 **Project folder:**  
`Task_1_Financial_Performance_Dashboard/`

---

### Task 2 – Global Superstore Sales & Customer Analytics

An interactive Power BI dashboard built using the Global Superstore dataset to analyze sales, profitability, customers, products, regional performance, and operational metrics.

**Dashboard pages:**
1. Executive Overview
2. Customer & Product Analysis
3. Regional & Operations Analysis

**Key areas covered:**
- Sales and profit analysis
- Customer analysis
- Product and category analysis
- Regional and market analysis
- Shipping and operational analysis
- Return analysis
- Year-over-year growth
- YTD performance

**Tools & Technologies:**
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
- Data Visualization

📁 **Project folder:**  
`Task_2_Global_Superstore/`
